# BudgetBook 디자인 적용 결과

기준: banking-app-references-2026-10-01.md

## 적용 범위

- 블루·라벤더 배경, 우윳빛 글래스 대표 카드, 반투명 상단 메뉴와 모바일 하단 탐색.
- 공통 색상·타이포그래피·버튼·입력창·선택 상태·알림·차트 툴팁·빈 상태·로딩 상태.
- 홈: 월/구성원 선택, 남은 예산 또는 소비 총액, 지출/수입 기록, 카드 결제 일정, 가족 자산, 최근 거래.
- 홈의 상세 분석은 추가 패널에 접어서 제공. 기존 사용자의 패널 선택은 유지하고 신규 기본값만 간결하게 변경.
- 내역: 목록과 달력 전환, 기존 검색/분류/구성원 필터와 수정·삭제 유지.
- 분석: 주요 요약 지표와 기존 카테고리·구성원·6개월 추이 차트.
- 자산: 현금·적금·주식·대출·월 예산 분리, 가족 총자산 요약과 별도 대출 원금 표시.
- 설정, 로그인/회원가입, 가족 생성/참여/초대 코드 화면.
- 파비콘과 공통 선형 아이콘.

## 모달·팝업

공통 Modal은 native dialog를 사용하며, 데스크톱 중앙 대화상자와 모바일 하단 시트로 대응한다. 배경 스크롤 잠금, Tab/Shift+Tab 포커스 순환, 닫은 뒤 초점 복원, Escape/배경 클릭 닫기, 저장 중 닫기 방지를 적용했다.

- 거래 추가/수정: 금액을 먼저 입력하고 저장 실패 시 입력값 유지.
- 현금 항목 추가/수정, 현금 기준 설정.
- 적금 추가/수정, 보유 주식 등록/수량 변경, 대출 추가/수정.
- 카드 결제 일정 상세.
- 신용카드 별명/결제일 수정: 두 번의 브라우저 prompt를 한 개의 검증 가능한 폼으로 교체.
- 거래·현금·적금·대출·주식·카테고리 삭제 확인.
- 데이터 초기화: 기존 두 단계 확인을 동일한 디자인으로 유지.
- 저장 결과와 오류 알림.

브라우저 기본 confirm/prompt/alert 호출은 앱 코드에서 제거했다. 날짜·색상·select 입력의 기본 선택 UI는 운영체제/브라우저 컨트롤을 사용한다.

## 데이터와 계산

데이터베이스 스키마와 API 구현은 변경하지 않았다. 예산 잔액과 현금 잔액을 구분하고, 자산 총액을 순자산으로 표시하지 않는다. 카드 결제 예정액은 지출 총액에 재합산하지 않는다.

예산 대표 금액은 가족 전체 조회에서만 표시한다. 구성원을 선택하면 해당 구성원의 소비 금액을 보여준다. 예산은 카테고리 한도 합계에서 미분류를 포함한 모든 지출을 차감하는 기존 기준이며, 홈에서 계산 기준을 펼쳐 확인할 수 있다.

지난달 비교는 현재 월일 때 같은 일자까지, 과거 월일 때 해당 월 전체를 비교한다. 전월 기록이 없는 경우 비교 문구 대신 기록 수를 표시한다.

## 검증

- `npm run build` 성공. 기존 설정에 따라 `docs/` 배포 산출물 갱신.
- 페이지 지연 로딩으로 코드를 분할해 빌드의 500kB 청크 경고 해소.
- `git diff --check` 통과.
- `tests/design-smoke.mjs` 실행 성공: 1440px 데스크톱, 768px 태블릿, 390px/320px 모바일 주요 화면의 가로 넘침 검사.
- 거래·신용카드·현금·적금·주식·대출 저장 실패 시 모달과 입력값 유지, 재시도 시 콜백 전달 확인.
- 삭제·초기화 취소 시 삭제 API가 호출되지 않음 확인.
- 모달의 키보드 포커스 순환과 닫은 뒤 포커스 복귀 확인.
- 빈 데이터, 예산 초과, 긴 금액/메모, 로딩 상태 확인.
- 로그인, 회원가입, 가족 참여 화면 확인.
- 런타임 및 콘솔 오류 없음 확인.

브라우저 검사는 별도의 Vite 테스트 서버에서 auth/hooks/API를 모의 데이터로 대체한다. 실제 계정 로그인, 운영 데이터 저장/삭제, 외부 배포는 수행하지 않았다. 모의 모듈은 실제 빌드에 포함되지 않는다. 화면 캡처는 `.test-results/design/`에 있으며 Git에서는 제외한다.

## 검사 재실행

Playwright가 설치된 환경에서 `node tests/design-smoke.mjs`를 실행한다. 외부 제공 런타임을 사용할 경우 `PLAYWRIGHT_MODULE_PATH`에 Playwright 모듈 절대 경로, `BROWSER_PATH`에 Chromium 계열 브라우저 실행 파일 경로를 지정할 수 있다. 테스트 서버는 127.0.0.1:5178을 사용하고 종료 시 닫힌다.
